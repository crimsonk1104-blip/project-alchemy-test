# v0.9 플레이어 무기 시험 프로토타입

기준은 feat/balance-config이다. 검·플레이어 HP·몬스터·자동인형 네 패턴·보상 경로의 기존 수치는 유지한다. 추가 무기는 임시 수치이며 정식 그래픽이나 직업/스킬 구현이 아니다.

현재 네 번째 시험 슬롯은 **연금 도구 · 시약 투척(시험)** 표현을 사용한다. 내부 `staff` 식별자와 정식 검·창·활·지팡이 분류는 유지하며, 승인 스토리는 수정하지 않는다. 구현·검증 범위는 [시약병 투척 문서](reagent-throw.md)를 참고한다. 아래 기존 지팡이 조준 수치는 시약 투척에서도 그대로 사용한다.

## 선택과 장비

첫 로비 메뉴의 시험대에서 검·창·활·시약 투척(시험)을 선택한 다음 지역을 선택한다. 전투 중에는 `지역 → 연구소 로비로 이동 → 지역 메뉴 다시 열기`로 돌아와 다른 무기를 선택한다. 기본 검으로 복귀하는 버튼이 시험 선택 해제 역할을 한다.

`state.activeWeapon` 하나만 실제 공격을 결정한다. 전투 샌드박스의 시험 선택은 아이템을 지급하지 않는다. CH01 면접 선택은 초기 지급 소유 장비를 1개 지급·장착하며, 교환 시 이전 초기 장비를 반납한다. 초기 장비 능력치 보너스는 0이며 반복 장착으로 누적되지 않는다. 과거 테스트 훈련검은 제거했고, 슬라임 퀘스트 보상은 보관 전용 초급 강화석 1개로 대체했다.

선택 시 입력·대기 클릭·기존 투사체·범위 공격을 정리하고 공격 중 상태를 해제한다. 쿨다운은 새 무기의 간격보다 짧게 초기화하지 않는다. 지역 이동은 기존처럼 전투 상태를 정리한다. 전체 다시 시작은 로비와 무기 선택 메뉴를 열고 기본 검·빈 테스트 인벤토리로 초기화한다. 단순 지역 이동과 훈련장 재입장은 선택 무기·보상·장비를 보존한다.

## 임시 수치 (balance-config.js)

기본 피해는 기본 공격력1일 때이며, `damageMultiplier`로 관리한다. 장비 보너스는 실제 사용 중인 스타일과 장착 장비가 일치할 때 계산한다. 현재 초기 장비 보너스는 모두 0이다.

| 무기 | 기본 피해 | 간격 | 범위 | 특징 |
|---|---:|---:|---|---|
| 검 | 1 | 0.39초 | 70, 전방90도 | 기존 베기 유지 |
| 창 | 1 | 0.58초 | 길이155, 폭20 | 즉시 직선 찌르기; 대상 몸 반경 포함 |
| 활 | 1 | 0.65초 | 최대380 | 속도440·반경6 화살, 첫 충돌 한 기에만 피해 |
| 네 번째 시험 슬롯 (`staff`) | 2 | 0.90초 | 직접 지정 거리45~240, 반경48 | 놓으면 투척, 0.35초 뒤 착탄 시 원형 범위 피해1회 |

활은 이동 선분과 적 원의 최초 교점을 사용해 빠른 투사체의 관통 누락과 뒤의 적 우선 타격을 막는다. 조준 보조는 활에만 적용하며 마지막 수동 방향 전방20도 안을 고려한다.

### 네 번째 시험 슬롯의 직접 위치 지정

Space/J 또는 공격 버튼을 누르면 조준을 시작한다. 캐릭터 이동은 멈추고 이동키·조이스틱은 방향을 제어한다. 캐릭터 위치에서 시작한 거리45가 0.7초까지 선형으로240으로 늘어나며 더 오래 눌러도240을 넘지 않는다. 0.08초 이내 탭은45에서 투척한다. 충전은 거리에만 영향을 주며 피해2는 동일하다.

공격키/버튼을 놓으면 마지막 좌표에 투척한다. 조준 원·연결선과 실제 착탄 피해는 동일한 좌표·반경48을 사용한다. 적을 검색하거나 조준 방향을 자동 보정하지 않는다. 투척 후에도 목표는 고정되며0.35초 뒤 범위 피해를 한 번 준다. 병의 공중 궤적에는 타격 판정이 없다. PC와 터치에 같은 groundTarget 함수를 사용한다. 조준 규칙은 함수 인자로 전달되며 렌더링 방식과 독립적이다.

Esc, 공격 버튼 밖에서 손 놓기, pointercancel/포인터 캡처 상실, 포커스 해제·숨김·화면 크기 변경, 일시정지·가방·지역 메뉴·무기 변경·재시작으로 조준을 취소한다. 취소를 발사로 해석하지 않는다. 키보드와 포인터는 조준 소유자를 구분해 다른 입력의 해제가 투척하지 못하게 한다. Space/J를 계속 유지해도 자동 반복하지 않는다.

쿨다운 중에도 다음 위치를 조준할 수 있으나, 준비되기 전에 놓으면 대기 안내만 표시하며 나중에 자동 발사하지 않는다. 최대 거리 충전 시간은 실제 경과 시간도 고려해 프레임 지연 때문에 지나치게 느려지지 않도록 한다.

## 조작과 시각화

기존 조이스틱·공격 버튼·검·창·활은 Space/J 유지 공격을, 시약 투척 시험은 누르기/놓기 공격을 사용한다. 터치 버튼의 단발/버퍼 규칙은 유지하며, 선택 버튼은 로비 메뉴에만 추가한다. 현재 시험 스타일은 HUD, 공격 버튼 아이콘, 캐릭터 옆 표식으로 구분한다. 시약 투척은 캐릭터 옆에 Canvas 병을 표시한다.

검만 기존 Ninja Adventure 공격 스프라이트·베기를 사용한다. 다른 무기는 기존 idle/walk 몸체 위에 Canvas 표식을 표시하고, 창은 찌르기 통로, 활은 화살, 네 번째 시험 슬롯은 Canvas 병의 포물선·파편·원형 시약 확산으로 표현한다. 이 무기들에 검 공격 애니메이션이나 베기 이미지를 재사용하지 않는다. 추가 이미지 파일을 참조하지 않는다.

`applyPlayerHit`, `spearHits`, `updatePlayerAttacks`, `assistedDirection`(활), `groundTarget`(공통 위치 지정)이 판정/갱신을 담당한다. `drawPlayer`, `drawEffects`가 임시 표현을 담당한다. 피해·방향·규칙을 공격 시점에 저장해 이후 장비 변화가 이미 발사한 공격을 중복 변경하지 않게 한다.

## 검증

`tests/player-weapons.cjs`는 네 무기×슬라임/자동인형 피해, 실제 공격으로 숲 퀘스트 및 네 무장 평가 완료, 장비 보너스 분리, 긴 창·좁은 판정, 화살 첫 충돌/수명, 비행 지연·착탄 범위·1회 피해, 제한 조준, 전환 취소/중복 방지, 초기화를 확인한다. 퀘스트 테스트는 적 위치와 시계를 통제해 판정과 상태를 검증하며, 적의 각 패턴 실행을 기다린 뒤 공격한다.

또한 실제 브라우저 키 입력과 실시간 프레임으로 각 무기의 슬라임 피해를 검증한다. 모바일3개 화면(360×640, 844×390, 820×1180)에서는 Chromium CDP의 멀티터치 입력과 PC 입력의 조준 결과 일치·피해를 확인한다. 기존 모든 회귀 테스트도 유지한다. 물리 기기의 엄지 조작감과 iOS Safari는 별도 확인이 필요하다.


추가 회귀 검증: `node tests/staff-aim-reset.cjs`. 제어된 시계와 실제 키/멀티터치 입력으로 조준 좌표·피해·취소를 비교하고, 실시간 프레임에서도0.85초 유지 시 최대 거리/무투척, 해제 시1회 투척을 검증한다. 기존 숲 전투 테스트의 명시적 forest 초기화와 시약 투척150거리 투척 픽스처는 새 조작 규칙에 맞춰 수정했다. 기존 보상·피해·장비·패턴 검증은 삭제하지 않는다.
