# 시약병 투척 전투 스타일 시험

기준 `fix/staff-aim-reset` / `98fc38a`, 작업 `feat/reagent-throw`.

사용자 표시명은 **연금 도구 · 시약 투척(시험)**이다. 내부 `staff` 식별자는 호환을 위해 유지한다. 정식 검·창·활·지팡이 분류, CHAPTER 01 대본, 자동인형의 지팡이 패턴은 변경하지 않는다. 정식 시약 장비나 소비 아이템을 지급하지 않는다.

## 조작과 공격 흐름

PC는 Space/J를 누른 채 WASD·방향키로 방향을 지정하고 놓으면 투척한다. 모바일은 오른쪽 공격 버튼을 누른 채 왼쪽 조이스틱으로 조준하고, 공격 버튼 안에서 놓으면 투척한다. 조준 중 캐릭터는 이동하지 않는다. 짧은 탭은 최소 거리, 길게 누르면 최대 거리까지 증가한다. 자동 조준과 유지 중 자동 반복 투척은 없다.

예상 착탄 원과 연결선을 표시한다. 놓는 시점의 원 중심·반경을 공격 데이터에 고정한다. 병은 0.35초 동안 포물선으로 이동하는 Canvas 임시 그래픽이다. 착탄 시 병 파편과 시약 확산을 표시하며 반경 안의 적에게 피해를 1회 적용한다. 비행 중 적 충돌, 지속 피해, 시약 소비는 없다. 확산 안에 나중에 들어온 적도 추가 피해를 받지 않는다.

수치는 `balance-config.js`를 기준 커밋에서 그대로 유지했다.

| 항목 | 값 | 설정 |
|---|---:|---|
| 최소/최대 거리 | 45 / 240 | `weapons.staff.minRange` / `range` |
| 최대 거리 충전 시간 | 0.7초 | `maxChargeTime` |
| 짧은 탭 유지 구간 | 0.08초 | `tapGrace` |
| 착탄 반경 | 48 | `blastRadius` |
| 기본 피해 | 2 (기본 공격력1 기준) | `damageMultiplier` |
| 공격 간격 | 0.9초 | `cooldown` |
| 비행·착탄 대기 | 0.35초 | `castDelay` |
| 착탄 후 표현 잔존 | 0.22초 | `effectDuration` |

범위 판정에는 기존 적 몸체 반경도 포함한다. 충전은 거리에만 영향을 준다. 쿨다운 중 놓은 입력은 예약하지 않으며 재사용 대기 안내를 표시한다.

## 최소 분리 구조

- `GROUND_ATTACKS`: 기존 슬롯과 공통 조준 규칙·표현 종류의 연결부. 현재 `staff` → `reagent` 한 종류만 등록.
- `groundTarget(aim, rules)`: 방향·충전 시간으로 좌표 계산. 적 검색·렌더링·무기 분류에 의존하지 않는다.
- `beginGroundAim` / `updateGroundAim` / `finishGroundAim` / `cancelGroundAim`: 입력 소유자, 키 유지, 중복 방지, 취소, 발사 시점 고정.
- `state.playerAreas` / `updateAreaAttacks`: 발사 원점·착탄 좌표·피해·남은 비행 시간·판정 완료 여부 관리. 시간이 도달하면 렌더링 없이도 피해를 1회 적용한다. 큰 프레임 간격도 처리한다.
- `drawGroundAim` / `AREA_RENDERERS` / `drawReagentAttack` / `drawReagentBottle`: 표현만 담당. `reagentFlightPose`의 공중 높이는 그림에만 영향을 주고 착탄 좌표는 바꾸지 않는다.

향후 지팡이 마법은 같은 조준·범위 판정에 다른 표현을 연결할 수 있다. 이번에는 미래 마법 효과나 새 무기·스킬을 추가하지 않는다. 숫자 밸런스 소스와 기존 단일 HTML 빌드는 유지한다. 추가 이미지 파일 요청도 없다.

## 중단·정리

Esc, 버튼 밖 놓기, 포인터 취소·캡처 상실, blur·화면 숨김·크기 변경, 가방·지역 메뉴·일시정지는 조준을 취소하고 놓기를 발사로 해석하지 않는다. 이미 던진 병은 기존 게임 일시정지 정책에 따라 멈췄다 이어진다. 지역 이동·전체 초기화·시험 스타일 교체는 비행/확산 데이터도 제거한다. 전체 다시 시작은 로비·기본 검·빈 데이터로 복귀하고, 지역 재도전은 선택 스타일·보상을 보존한다.

## 검증

`node tests/reagent-throw.cjs`: 기준 커밋과 전투 수치 동일(별도 승인된 장비·보상 정리 제외), 짧은/긴 충전, 포물선 중간 위치, 0.35초 이전 미타격·착탄 1회 타격, 경로 미충돌, 반경 경계, 늦게 들어온 적 미타격, 렌더링 독립·무상태 변경, 큰 시간 간격, 일시정지·지역 이동·초기화·교체 정리, 잔존 효과 소멸. 실제 Chromium 키 이벤트와 실시간 RAF에서도 비행→착탄→소멸을 확인한다.

기존 `tests/staff-aim-reset.cjs`와 `tests/player-weapons.cjs`는 공통 함수·상태 이름으로만 연결을 바꿨으며 기존 단언을 유지한다. PC·터치 좌표 일치, 3개 모바일 화면의 네이티브 멀티터치, 입력 소유자·취소, 네 전투 스타일 피해, 퀘스트·장비·초기화 검증을 계속 수행한다. 나머지 전투·보상·AI·지역·전체 화면 회귀 테스트도 실행한다.

실제 휴대폰·태블릿의 물리 조작감과 iOS Safari는 별도 사용자 확인이 필요하다. 이번 결과는 Canvas 전투 프로토타입이며 정식 그래픽 제작 완료를 의미하지 않는다.

검증 결과: 신규 시약 투척 테스트와 기존 12개 회귀 스크립트 모두 통과했다. Chromium 실시간 관측에서 비행20프레임·착탄 표현14프레임, 첫 비행 관측부터 착탄 관측까지 약333ms였으며 설정 시간은0.35초다. 모바일360×640·844×390·820×1180에서 조준/공격 멀티터치를 통과했고, 기존 레이아웃 테스트는390×844·1180×820도 포함한다. `node scripts/build-balance.cjs --check` 및 인라인 스크립트 구문 검사도 통과했다. WebKit 실행 파일이 없어 iOS Safari 검증은 미실행으로 남긴다.
